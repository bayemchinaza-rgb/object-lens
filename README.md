# object-lens

Point your camera at an everyday object and get an instant guess. MobileNetV3 runs entirely in your browser, with no server and no uploads.

**Live site:** https://bayemchinaza-rgb.github.io/object-lens/

Recognizes 1000 ImageNet categories (animals, vehicles, food, tools, furniture and more) and shows the top 3 guesses. It always picks the closest match, so it can be wrong on things it has never seen.

Built with TensorFlow/Keras, TensorFlow.js, HTML/CSS/JavaScript and GitHub Pages.
